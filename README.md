# Маятник

HTML5-игра для Yandex Games: маятник с шаром на цепи (Three.js + cannon-es). **Шаг 3:** экран «Конец», рекорд и «Поделиться».

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (по умолчанию `http://127.0.0.1:43123`).

## Управление

- Тап или клик в **левую** половину экрана — качнуть влево.
- Тап или клик в **правую** половину — качнуть вправо.

## Правила (шаг 2)

- Удар по **мятным** блокам разрушает их и даёт **+1** к счёту.
- Удар по **коралловым (красным)** блокам — **конец раунда** (башни осыпаются, экран «Конец»).
- Со временем качание **чуть ускоряется** (сложность растёт).

## Экран «Конец» и шаринг (шаг 3)

- Две кнопки **одинакового размера**: «Ещё раз» и «Поделиться».
- «Ещё раз» — новый раунд, счёт сбрасывается; **рекорд** сохраняется в браузере.
- «Поделиться» — Web Share API (текст + ссылка, при поддержке — скриншот); иначе копирование ссылки и тост «Ссылка скопирована».

## Сборка

```bash
npm run build
npm run preview
```

Статика для деплоя лежит в `dist/`.

## Структура

- `src/game/` — сцена, камера, визуал маятника, ввод
- `src/physics/` — мир cannon-es и маятник
- `src/ui/` — счёт (pill) и экран конца раунда
