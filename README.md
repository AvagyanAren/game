# Башня — первый слайс

HTML5-игра (Canvas 2D + Vite): башня в центре, одно орудие, прямые пули, три фигуры снаружи.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (по умолчанию `http://127.0.0.1:43123`).

## Управление

- Удерживайте палец или кнопку мыши и наводите — направление прицела обновляется только пока нажато.
- Отпустите — прицел остаётся; орудие продолжает стрелять по этой линии.

## Баланс (заглушки)

Числа в `src/tower/config.ts` (`PLACEHOLDER_BALANCE`) — не финальный баланс.

## Сборка

```bash
npm run build
npm run preview
```

Статика для деплоя лежит в `dist/`.
